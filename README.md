# ふたりの九州旅

2026年9月13日〜17日の熊本・阿蘇・宮崎旅行をまとめたスマートフォン向けしおり。

このリポジトリのルートが公開する静的サイトです。ビルド・外部API・データベースは不要です。GitHub Pages は main ブランチの / (root) を公開します。

## 内容

- 5日分の旅程。予約確認済み・本人共有・未予約の提案を区別
- 空港、菊南温泉、桜町バスターミナル、宮崎駅、シーガイアの移動ガイド
- 草千里といまきん食堂へのドライブ案、車がない場合の代案
- あか牛、天草の寿司、太平燕の候補と公式・地図リンク
- 生成した4点のイメージイラスト。実際の景色・料理写真としては使用しない

## 更新

日程・説明・公式リンクは `app.js`。共通スタイルは `style.css` と `details.css`。画像は `assets/`。
予約番号、チケットのアクセスURL、氏名、メールアドレス、個人の連絡先は保存していません。
